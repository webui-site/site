# OnePager — сайт-визитка

Премиальный OnePager для шапки Instagram / Threads / YouTube. Тёмный
градиентный стиль, стеклянные карточки, лёгкие анимации. Две страницы:

- **`index.html`** — главная: PDF-гайд, Telegram-канал, YouTube и кнопка «о бизнесе».
- **`business.html`** — отдельный лендинг о бизнесе: продающее видео + кнопка «написать в личный Telegram».

---

## Как вставить свои ссылки (2 минуты, без навыков программирования)

Все настройки лежат **в самом низу каждого файла**, в блоке `CONFIG`.
Открой файл любым текстовым редактором (или прямо на GitHub — карандашик ✏️)
и меняй текст **только между кавычками**.

### 1. `index.html` — главная

| Что | Поле в CONFIG |
|-----|---------------|
| Имя / бренд | `name`, `monogram`, `initials` |
| Фото (по желанию) | `photo` — ссылка на картинку, напр. `"avatar.jpg"` |
| Текст под именем | `role` |
| Название и цена гайда | `guide.title`, `guide.price`, `guide.priceOld` |
| **Ссылка на оплату гайда** | `guide.payLink` |
| **Telegram-канал** | `telegramChannel` |
| **YouTube** | `youtube` |
| Личный Telegram (иконка в футере) | `personalTelegram` |
| Instagram / Threads (иконки) | `instagram`, `threads` |

### 2. `business.html` — страница о бизнесе

| Что | Поле в CONFIG |
|-----|---------------|
| **Продающее видео** | `videoEmbed` |
| **Личный Telegram (главная кнопка)** | `personalTelegram` |
| Заголовки и тексты | `title`, `subtitle`, `ctaHeading`, `ctaText` … |

> ⚠️ Ссылки должны начинаться с `https://`. Чтобы **скрыть** ненужный элемент
> (например, у тебя нет Threads) — поставь пустые кавычки `""`. Незаполненный
> плейсхолдер `"https://"` остаётся видимым как заглушка, но ведёт в никуда,
> поэтому перед публикацией впиши настоящие ссылки.

## Как взять embed-ссылку для видео (YouTube)

1. Открой своё видео на YouTube → **«Поделиться»** → **«Встроить»**.
2. В коде найди `src="https://www.youtube.com/embed/XXXX"` и скопируй адрес.
3. Вставь его в `videoEmbed` в `business.html`.

## Как опубликовать бесплатно

Это обычные HTML-файлы — работают на любом хостинге. Проще всего:

**GitHub Pages:** Settings → Pages → Branch: выбрать ветку → папка `/root` → Save.
Через минуту сайт будет доступен по ссылке вида `https://<логин>.github.io/<репозиторий>/`.

Другие бесплатные варианты: Netlify, Vercel, Cloudflare Pages — просто
перетащи папку в их интерфейс.

---

## Проверить локально

Двойной клик по `index.html` — откроется в браузере. Всё работает без сервера.
