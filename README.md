# OnePager + воронка из двух видео

Премиальный сайт-визитка для шапки Instagram / Threads / YouTube. Тёмный
стиль, стеклянные карточки, один аккуратный цвет-акцент (без «радужных»
кнопок), лёгкие анимации.

## Файлы — что за что отвечает

| Файл | Назначение |
|------|-----------|
| `index.html` | Главная страница (эта ссылка идёт в шапку Instagram/Threads/YouTube): блок «Мой бизнес», PDF-гайд, ссылки на канал и YouTube, соцсети |
| `business.html` | Воронка, шаг 1: видео №1 + кнопка «Посмотреть второе видео» |
| `business2.html` | Воронка, шаг 2: видео №2 + кнопка «Написать в Telegram» |
| `avatar.jpg` | Твоё фото для главной. Чтобы заменить — положи новое фото с тем же именем |
| `README.md` | Эта инструкция (на сайт не попадает) |

```
index.html ──► business.html ──► business2.html ──► личный Telegram
   (шапка         (видео 1)          (видео 2)
   профиля)
```

Логика воронки: человек смотрит **видео 1** → если интересно, жмёт кнопку и
переходит на **видео 2** → после него появляется кнопка написать тебе в
Telegram. Это мягкий этап отсева: пишут уже «тёплые» люди.

> **Сейчас воронка выключена:** пока видео не записаны, кнопка «Мой бизнес»
> на главной ведёт прямо на Telegram-канал. Чтобы включить воронку: в
> `index.html` поменяй `businessLink` на `"business.html"` и вставь ссылки
> `video1` / `video2` в файлах воронки.

## Как вставить свои ссылки (без навыков программирования)

Все настройки — **в самом низу каждого файла**, в блоке `CONFIG`.
Открой файл текстовым редактором (или прямо на GitHub — карандашик ✏️) и
меняй текст **только между кавычками**.

### `index.html` — главная

| Что | Поле |
|-----|------|
| Имя / бренд | `name`, `brand`, `monogram`, `initials` |
| Фото | `photo` (файл `avatar.jpg` лежит рядом с сайтом) |
| Текст под именем / чипы доверия | `role`, `chip1`, `chip2` |
| Гайд: название, описание, цена | `guide.title`, `guide.desc`, `guide.price` |
| Гайд: кнопка и подпись под ней | `guide.buttonText`, `guide.note` |
| **Куда ведёт кнопка гайда** | `guide.payLink` — сейчас личный TG; когда появится автоматизация, замени на прямую ссылку оплаты |
| **Telegram-канал** | `telegramChannel` |
| **YouTube** | `youtube` |
| **Куда ведёт блок «Мой бизнес»** | `businessLink` — сейчас TG-канал; для запуска воронки поставь `"business.html"` |
| Тексты блока «Мой бизнес» | `biz.kicker`, `biz.title`, `biz.desc`, `biz.cta` |
| Личный Telegram / Instagram / Threads (иконки внизу) | `personalTelegram`, `instagram`, `threads` |

### `business.html` — видео 1

| Что | Поле |
|-----|------|
| **Первое видео** | `video1` |
| Тексты | `title`, `subtitle`, `kicker` … |

### `business2.html` — видео 2

| Что | Поле |
|-----|------|
| **Второе видео** | `video2` |
| **Личный Telegram (главная кнопка)** | `personalTelegram` |
| Тексты | `title`, `subtitle`, `ctaHeading` … |

> ⚠️ Ссылки должны начинаться с `https://`. Чтобы **скрыть** ненужный элемент
> (например, у тебя нет Threads) — поставь пустые кавычки `""`. Плейсхолдер
> `"https://"` остаётся видимым как заглушка, но ведёт в никуда — впиши
> настоящие ссылки перед публикацией.

### Как взять embed-ссылку видео (YouTube)

1. Открой видео → **«Поделиться»** → **«Встроить»**.
2. Скопируй адрес из `src="https://www.youtube.com/embed/XXXX"`.
3. Вставь его в `video1` / `video2`.

### Поменять цвет-акцент

В начале `<style>` каждого файла есть `--accent:#6b7cff;`. Поменяй значение —
и перекрасятся все кнопки и акценты разом.

## Как опубликовать бесплатно (и чтобы открывалось в России)

Это обычные HTML-файлы — работают на любом статическом хостинге. Ниже —
бесплатные варианты, доступные по всему миру. **Самое надёжное для России —
подключить свой домен** (тогда доступ не зависит от блокировок доменов
платформы).

### Вариант 1. GitHub Pages (проще всего, если уже на GitHub)

1. Загрузи файлы в репозиторий (уже сделано).
2. **Settings → Pages**.
3. **Source:** Deploy from a branch → выбери ветку и папку `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет на `https://<логин>.github.io/<репозиторий>/`.
5. Домен `github.io` в России, как правило, открывается. Для гарантии — п. «Свой домен» ниже.

### Вариант 2. Vercel

1. Зарегистрируйся на [vercel.com](https://vercel.com) через GitHub.
2. **Add New → Project** → выбери этот репозиторий → **Deploy**.
3. Готово: сайт на `https://<имя>.vercel.app`. Правки в репозитории
   деплоятся автоматически.

### Вариант 3. Cloudflare Pages

1. [pages.cloudflare.com](https://pages.cloudflare.com) → **Create a project**.
2. Подключи репозиторий → framework preset: **None** → **Deploy**.
3. Сайт на `https://<имя>.pages.dev`. У Cloudflare широкая сеть — обычно
   стабильно открывается в РФ.

### Вариант 4. Netlify (без Git — перетащить папку)

1. Зайди на [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащи папку с файлами прямо в окно браузера.
3. Через несколько секунд получишь ссылку `https://<имя>.netlify.app`.

### Свой домен (рекомендую для стабильного доступа в РФ)

1. Купи домен (например, reg.ru, Timeweb — с оплатой из РФ; или Namecheap).
2. В настройках выбранного хостинга (любого из вариантов выше) → **Custom
   domain** → добавь домен и пропиши указанные DNS-записи у регистратора.
3. Свой домен + Cloudflare-проксирование даёт максимально надёжный доступ по
   всему миру.

> 💡 Шрифты подгружаются с Google Fonts (обычно доступны в РФ). Если хочешь
> полностью убрать внешние зависимости — скажи, «зашью» шрифты в файлы, чтобы
> сайт не зависел ни от каких сторонних сервисов.
